# 喵言喵 v1.8.0

- 新增 Android 版 Discord 聊天输入框自动改字适配。
- 输入事件到达后立即安排处理，取消原有固定等待，不再依赖发送点击触发。
- 修复删字、插入文字和输入法选词后整条消息停止处理的问题。
- 改写时恢复光标和选区；同一条消息的后缀、尾缀及颜文字保持固定选择。
- 输入框暂时不可用或写回失败时自动重试，并在输入后短时检查漏掉的变化。
- 原「发送触发」调整为「停顿处理」，短暂停顿后自动补齐后缀；保留「实时处理」。

沿用聊天应用原有的输入和发送方式，无需额外按钮。

## 验证范围

33 项单元测试通过，覆盖原文位置映射、连续编辑、写回重试的数据处理、稳定后缀和 Discord 输入框识别。
当前没有连接的 Android 设备，ColorOS 15 以及各版 QQ、Discord 的真实事件时序仍需用户反馈确认。
Discord 先适配普通文本输入框。系统若暴露包含特殊提及组件的富文本，保持原样，避免丢失提及信息。
