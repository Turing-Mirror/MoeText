# 喵言喵 v1.7.3

- 修复输入框识别在部分 ROM 上间歇失效、「第一次可以，后面失效」的问题：读取文本前刷新节点，焦点丢失时仍能定位输入框，改查目标应用全部窗口并按资源 ID 兜底，快速重试耗尽后降为慢速轮询。
- 适配 QQ 新版本缩短的资源 ID；无法匹配时接受窗口下部的多行输入框，识别成功后优先沿用该 ID。
- QQ 内置表情编码不再被替换或后缀拆开；包含 @ 提及的消息不再改写，避免提醒失效。
- 空输入框与隐藏文本按光标位置区分，切换会话恢复的草稿不再重复追加后缀。
- 规则页所有改动即时生效，移除「保存设置」按钮。
- 减少无聊天输入框页面的持续重试，自动检查更新改为每会话一次，完善诊断日志。

## 验证范围

单元测试覆盖原文位置映射、连续编辑、QQ 表情编码保护、@ 提及识别与输入框兜底逻辑。
当前没有连接的 Android 设备，ColorOS 15 以及各版 QQ、Discord 的真实事件时序仍需用户反馈确认。
