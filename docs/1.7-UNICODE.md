# 1.7.0 开发记录

## 本次实现

- 新增 Unicode 页面，提供群昵称生成、控制字符清理、正文保护和加强保护。
- 提供昵称、提及消息、保护消息三种预览，以及宽窄布局切换。
- 支持复制实际控制字符，字符分析默认折叠。新增页面使用中英文资源。
- 修复未完成句子丢失、空白丢失、单复数规则干扰和预览随机重算。
- 保留页面草稿；导入导出在后台执行，导入文件限制为 256 Ki 个字符。
- 修复预设中短词提前替换导致长词失效的问题。
- 更新配置通过监听持久化变更生效。服务状态显示连接状态，不再声称已验证正常运行。
- 写回前验证焦点、包名、输入框 ID 和原文是否变化，写回后验证完整文本。
- 移除剪贴板回退写入和不可靠的装饰剥离器；手动修改已转换文本后暂停该消息的自动处理。
- 更新下载链接限定 HTTPS，更新响应大小限制为 64 Ki 个字符。

## 验证范围

自动化覆盖示例昵称、控制字符清理、嵌套闭合、段落重置、混合语言、代理对、
未完成句子、原文空白和单复数规则。16 项单元测试通过，Debug 构建通过。
Android Lint 为 0 个错误、9 个警告，主要涉及现有依赖版本、电池权限与图标配置。

当前环境没有连接的 Android 设备，也没有安装模拟器。尚未完成以下人工验收：

1. QQ 不同版本和系统上的真实提及效果、昵称长度限制、长消息换行。
2. 输入法候选词、发送前事件时序、同窗口切换聊天、手动编辑后恢复。
3. 浅色、深色、大字体、横屏、复制后粘贴和系统无障碍朗读。

浏览器页面不能替代原生 Android 页面或 QQ 客户端验收，因此未制作模拟网页截图。
本版按维护者决定作为正式版发布到 GitHub 和 CNB，并更新 CNB 的 latest.json。
