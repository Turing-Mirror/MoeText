# 喵言喵 v1.7.0

## 新增功能

- 新增 Unicode 群昵称生成，可自定义基础昵称和尾部文字。
- 新增昵称控制字符清理、正文保护和加强保护。
- 提供昵称、提及消息和保护消息预览，支持宽窄布局切换。
- 支持复制生成结果，以及展开查看控制字符和文本长度。

## 修复与优化

- 修复未完成句子被截断、空白丢失和单复数替换互相干扰的问题。
- 保留切换页面时的草稿，减少预览随机重算。
- 优化配置导入导出、预设替换顺序和导航栏触控区域。
- 加强聊天输入框写回校验，移除可能误删原文的反向剥离和自动剪贴板覆盖。
- 手动修改已转换文字后暂停当前消息的自动处理，清空输入框后恢复。

## 使用说明

在 QQ 中选择真正的 @ 对象，再粘贴保护后的正文。清理昵称不会修改对方的群昵称。
本地预览不等同于 QQ 的真实排版；版本、换行和昵称长度限制可能影响结果。
发送点击事件不能保证赶在 QQ 发出消息前完成处理。

16 项单元测试及 Debug 构建通过，Android Lint 无错误。QQ 真机兼容性尚未逐项验证。
如遇问题，请在 GitHub Issues 提供 Android 和 QQ 版本、复现步骤及不含私人信息的示例。
